## 四项收尾都已完成

1. **猫笔刀文章正文 —— 已解决，全自动**。关键：RSS 的 **`content:encoded` 元素里就是全文 HTML**（我一开始误读成 `description`，那是空的，才以为"RSS 不带正文"）。现在一条 `news.py article` 就拿到 标题+日期+链接+正文（实测 2,120 字），**不需要登录、不需要微信、不需要浏览器**。
   第二条独立源：备份站 `maobidao.net` 的 WordPress REST API（`...rest_route=/wp/v2/posts&categories=1`）→ `content.rendered` 也是全文，且内嵌带 `chksm` 的 mp 原文链。RSS 取不到正文时自动回退到它。**两条互不依赖才叫防删。**

   **拿历史文章（关键，别再用单篇链接）**：单个文章链接**只能拿到那一篇**。历史走两条命令：
   ```bash
   news.py article --all        # RSS 全部条目（约 20 篇，幂等，可反复跑）
   news.py backfill --pages 3   # 备份站翻页（实测 236 篇 / 3 页 / 每页 100，可回溯到 2025-03）
   ```
   已入库 **235 篇、跨度 2025-03-07 → 2026-10-11、全部带正文**。
   备份站那条链**不依赖任何 id**（只有那个站不做备份才会断）；RSS 的 feed id（`33d986064f59be5263de2ca822fb3e0bdd59eb81`）是 wechat2rss **第三方分配**的，无法从公众号的 `__biz` 推导（已试 md5/sha 各种组合，都不匹配）——它停服就断，所以才要两源。

   ⚠️ **备份站的 `date` 是"备份发布日"，比文章实际发布日晚约一天** → 跨源去重唯一键必须用 **(account, title)**，不能用日期（用日期会同一篇存两份：255 vs 235）。代价：只有备份站来源的那些篇，日期可能晚一天。
2. **`latest_news` / `latest_research` 工具 —— 已注册并实测**（问「光伏」返回真实快讯带时间与标签）。
3. **日报生成器 —— 已完成**：`report.py daily`，四块全从 sqlite 取数，产物 `data/reports/daily/<日期>.html` + 存档进 `reports` 表。实测 15,057 字节，18 行偏离 / 16 项异动 / 12 条相关要闻 / 8 篇相关研报 / 含文章正文。

## 别踩的坑（都实测过）

0. **launchd 跑不了这个项目：macOS TCC 保护 `~/Desktop`**。后台任务读桌面目录会直接被拒（日志里是 `Operation not permitted`，不是找不到文件）。三个 plist 已版本化在 `assistant/launchd/` 但**已从 LaunchAgents 卸载**。要用 launchd，必须**把项目移出桌面**（或给 `/bin/zsh` 完全磁盘访问权限）。现在的定时走 ZCode 内置定时任务，绕开了这个限制。
1. **RSS 全文在 `content:encoded`，不在 `description`**（后者是空的）—— 读错元素会以为"拿不到正文"。
2. **同一个文章链接不要连发两次请求**：第二次会被限流返回反爬验证页（17KB，无 `js_content`）。取一次 HTML 复用。
3. 扩展里用 `fileURLToPath`，**不要用 `URL.pathname`**（中文路径会被 percent-encode → `execFile` ENOENT）。
4. **ETF 不能用未复权行情价拟合基线**：分红会压低序列（512800 上市 0.9990→现 0.8500，而银行指数在涨；515880 未复权 0.5920 vs 累计净值 3.5526）。已走累计净值，退未复权时**状态里会打 ⚠**。
5. ETF 只取**稀疏点**（年末+最新），所以**ETF 贝塔算不了**（要日频）→ 用其跟踪指数代替。缓存文件名带口径。
6. 东财**行情**接口被网络层立即重置（0.1s，非限频）；**净值**接口可用。必须多源回退。
7. `stock_zh_index_hist_csindex` **首行是 base-date 合成行**要丢；`index_hist_sw` 用裸代码。
8. 同花顺 `tags` 是 **list[dict]**，直接 join 会 TypeError。
9. **抓取顺序先快后慢**（指数在前，ETF 在后）。
10. **大配置文件别整体重写**（watchlist 重写时丢过 `baseline:`）。
11. launchd 的 `ProgramArguments` 是**数组，只能放 `<string>`**，放 `<key>` 会 `bootstrap` 失败（Input/output error）。

## 口径红线（别改）

- 日报 09:00 生成 ⇒ 数据截至**上一交易日收盘**；文章是前一交易日那篇，**必须显式标注发布日期**（RSS 有 0–24h 延迟）。
- 基线是**冻结**的，不随新数据重拟合；展示必带 **R²**，R² 低就别下趋势结论。
- 贝塔基准 **中证500**，**只有 ETF 出**。
- 只读外部、只写 `assistant/` 与 `/tmp`、不写 `~/ic_backtest`、不碰 `packages/`。
